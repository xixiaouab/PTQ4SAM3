# PTQ4SAM3

**Semantics-Preserving Post-Training Quantization for Segment Anything Model 3**

[Project website](https://xixiaouab.github.io/PTQ4SAM3/) · [Website source](https://github.com/xixiaouab/PTQ4SAM3)

## Overview

PTQ4SAM3 studies how to preserve prompt-conditioned semantics when quantizing Segment Anything Model 3. Its method combines semantic anchors, orthogonal rectification, and temporal alignment for image and video segmentation.

This repository hosts the project website, including the method overview, figures, research highlights, and citation information.
